Figma2Beefree

Product Designer · Personal project · April–May 2026

TL;DR

Designers mock up email templates in Figma, but there's no bridge from that canvas into Beefree — every layout gets rebuilt by hand, and small details drift in the handoff. I built a Figma plugin that lets you compose an email visually on the canvas — rows, columns, headings, buttons, images, dividers — using Figma's own native controls, then export it straight into Beefree's schema. A one-click path takes it further: convert, enrich, and import the finished template into a real Beefree account without ever leaving Figma.

The problem

Beefree's email builder and Figma's canvas don't speak the same language. A designer can mock up a perfectly pixel-accurate template in Figma, but turning it into something Beefree can actually render means a developer manually re-creating every row, column, and module, translating fonts, paddings, and colors by hand. It's slow, and every manual step is a chance for the final template to drift from the design.

What I built

A Figma plugin with a module palette — Row, Heading, Paragraph, Button, Image, Divider, List, Menu, Icons — that inserts real Figma nodes onto the canvas, laid out on a 12-column grid so column widths never need manual resizing. Every node carries its Beefree-relevant properties (font, radius, padding, alignment) as plugin data, so editing stays entirely inside Figma's native property panel instead of a custom UI bolted on top. Selecting a template frame and exporting produces a valid Beefree Simple Schema JSON — structured rows and weighted columns that map 1:1 to what's on the canvas.

Closing the last gap

Simple Schema isn't what Beefree's own editor opens — it needs a more enriched "Full" JSON, so a raw export still wasn't an importable template. I added an Optimize tab that re-enriches exported JSON with the Figma-only properties Beefree's own conversion step drops, and a One-click tab that chains the whole thing together: convert, enrich, log in, and import into the user's Beefree project in a single click. Since Beefree's conversion API won't accept requests from a Figma plugin's sandboxed iframe (it sends Origin: null, and the response has no CORS headers), I stood up a small Cloudflare Worker to proxy the request and pass through the credentials the user enters — session-only, nothing stored.

Where it stands

8content module types supported
4tabs: Build, Export, Optimize, One-click
1 clickfrom Figma canvas to a live Beefree import
12-colgrid fidelity between canvas and schema

It's an unpublished, dev-mode plugin for now — anyone who wants to run it clones the repo and imports the manifest locally — but end to end it works: build a layout on the canvas, and one click later it's a live template in Beefree.

Reflections

The best UI for this plugin was the one I didn't build — routing every property through Figma's native panel instead of a custom editor made the tool feel familiar from the first use. And schema fidelity turned out to be a chain: Simple Schema, Full Schema, Beefree's own conversion API, a CORS proxy — the "1:1 replication" promise only holds if every link holds, which is what pushed the project from a plugin into a small plugin-plus-service system.
